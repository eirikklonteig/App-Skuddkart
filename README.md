# Skuddkart

Enkel skuddstatistikk for håndball, laget for Tune IL.

Registrer skudd under kampen med noen få trykk: hvem som skjøt, hvor på banen
skuddet kom fra, hvor på målet det gikk og om det ble mål, redning eller utenfor.

## Funksjoner

- Spillerliste med keepere og utespillere
- Kamper med kampklokke og valgfri omgangslengde
- Skuddregistrering for begge lag, med banesoner og 3 × 3 soner i målet
- Tidslinje med stilling, tidsretting og angre
- Sikkerhetskopi til og fra fil

Planlagte funksjoner står i [IDEER.md](IDEER.md).

## Bruk

Appen kjører i nettleseren (Chrome på PC, mobil og nettbrett).
Alle data lagres lokalt i nettleseren på enheten du bruker. Ta jevnlig
sikkerhetskopi under «Mer».

## Teknisk

Vanlig HTML, CSS og JavaScript, uten byggesteg. Publiseres med GitHub Pages.
